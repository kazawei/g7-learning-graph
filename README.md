# 初一（广州）学习图谱

给一个 12 岁、在广州读初一的孩子做的学习工具。核心是**知识图谱 + 自适应诊断**：选一个目标知识点或整册，程序先问目标本身；答错再出确认题，确认题还错才沿先修关系往回追，最后给出薄弱根因和一条按年级排序的补学路径。

## 里面有什么

| 目录 | 内容 |
| --- | --- |
| `data/` | 4,068 个知识点、6,429 条先修关系、16,419 道题、972 条课标条目（数学、英语、语文、物理、化学、生物、历史、地理、道法、科学） |
| `diagnose/` | 自适应诊断引擎与页面（纯静态，无后端；进度存 localStorage） |
| `explore/` | 知识图谱浏览（Cytoscape + dagre） |
| `children/` | 孩子档案（可建多个孩子、按科目存诊断记录） |
| `wrongbook/` | 错题本 |
| `g7/` | **初一（广州）入口页**：数学七上、英语七上整册诊断，其他学科直达 |
| `english/` | 已有的沪教牛津七上材料：越秀期末模拟 A/B、期中机考、语法诊断台、音标课件、可打印期中卷 |

## 给初一孩子怎么用

1. 先打开 `children/` 建一个档案，年级选七年级。
2. 每周选一科做一次「整册诊断」，20—30 题，不要一次刷完。
3. 结果页只看三件事：薄弱根因、不稳的点、按年级排序的学习路径；先补路径最前面的两个。
4. 隔三天复测同一年级，看薄弱点有没有往前移。
5. 考前只看 `wrongbook/`，不再重刷整卷。

入口：`g7/index.html`。

## 教材口径（重要）

- **数学**：人教版 2024 审定版，七上从有理数到几何图形初步。
- **英语**：原图谱按人教版 Go for it! 新版建点，不是沪教牛津。语法点大部分重合，但单元顺序、词汇表不同。英语校内同步以学校教材为准；图谱用来查语法漏洞，不用来背单元词。
- 其他学科按各自版本（语文统编、道法统编、历史统编、地理人教版、生物人教版）。
- 诊断数据是 AI 初稿，先修关系未经一线教师逐条审核，结论只作参考。

## 本地运行

页面通过 `fetch('../data/*.json')` 读数据，**不能直接双击 `index.html`**，需要起一个静态服务器：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000/g7/
```

## 部署

仓库根目录就是静态站点根目录，已带 `.nojekyll`，可直接用 GitHub Pages（Deploy from a branch，`main` / `/`）。
